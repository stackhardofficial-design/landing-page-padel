# POWER PADEL • Club & Pro-Shop Oficial

Landing page premium de alta gama para el complejo deportivo y pro-shop oficial de Power Padel en Mendoza, Argentina.

## Características Técnicas

- **Stack**: Next.js 16 (App Router con Turbopack), React 19, Tailwind CSS v4, TypeScript.
- **Animaciones & Microinteracciones**: Framer Motion, cursores inerciales contextuales, Split Text reveal, Tilt 3D con spotlight radial y Canvas Confetti.
- **Sistema de Reservas en Tiempo Real**: Gemelo digital 3D isométrico / 2D de las 3 pistas panorámicas homologadas, selector de fecha y horario, calculadora de división de tarifa entre jugadores (*Split-Pay*) y emisión de Boarding Pass oficial.
- **Telemetría & Laboratorio de Palas**: Gráfico Radar SVG interactivo de 5 ejes (Potencia, Control, Rebote, Efecto 3D y Punto Dulce) y simulador lumínico de pista (Día / Nocturno LED 800 Lux) con puntos de inspección técnica.
- **Globo 3D Interactivo**: Visualización cartográfica interactiva con COBE para eventos corporativos y torneos.

## Puesta en Marcha Local

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) en tu navegador para ver la aplicación.
